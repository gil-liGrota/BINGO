באייפון (iPhone - דפדפן Safari):

    פתחי את הדפדפן Safari בטלפון והיכנסי לקישור של משחק הבינגו שלך.

    בתחתית המסך (או למעלה), לחצי על כפתור השיתוף (סמל של ריבוע עם חץ כלפי מעלה).

    גלול בתפריט שנפתח וחפשי את האפשרות "הוסף למסך הבית" (Add to Home Screen).

    תוכלי לשנות את שם האתר אם תרצי, ולאחר מכן לחצי על "הוסף" (Add) בצד ימען.

    הופס! אייקון של המשחק יופיע כמו אפליקציה רגילה במסך הבית שלך.

באנדרואיד (Android - דפדפן Chrome):

    פתחי את דפדפן Chrome בטלפון והיכנסי לקישור של המשחק.

    לחצי על שלושת הנקודות בפינה הימנית (או השמאלית) העליונה של הדפדפן כדי לפתוח את התפריט.

    בחרי באפשרות "הוסף למסך הבית" (Add to Home screen) או "התקן אפליקציה" (Install app).

    אישרי את ההודעה שתופיע, והקיצור הדרך יתווסף מיד למסך הבית שלך.

זהו! מעכשיו תוכלו להיכנס למשחק בלחיצת כפתור אחת בדיוק כמו אפליקציה אמיתית. בהצלחה!
